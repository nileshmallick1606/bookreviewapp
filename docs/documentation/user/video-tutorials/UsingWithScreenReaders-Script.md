# Video Script: Using BookReview with Screen Readers

**Video Title:** Using the BookReview Platform with Screen Readers  
**Duration:** 3:45 minutes  
**Target Audience:** Users with visual impairments  
**Video Type:** Accessibility Tutorial

## Script Overview

This video demonstrates how to effectively use the BookReview Platform with screen readers, showing navigation techniques, keyboard shortcuts, and accessibility features specifically designed for users with visual impairments.

## Technical Requirements

- Screen recording of the BookReview Platform with screen reader active
- Visible keyboard shortcuts displayed on screen
- Audio demonstration of screen reader output
- Visual highlighting of focus states and navigation paths
- Clear, slower-paced narration
- BookReview Platform logo animations for intro/outro

## Introduction (0:00 - 0:30)

**[Visual: BookReview Platform logo animation fades in with accessibility icon]**

**Narrator:** Welcome to this accessibility tutorial for the BookReview Platform. Today, we'll demonstrate how to effectively use our platform with screen readers, ensuring that all readers can discover and discuss books regardless of visual ability.

**[Visual: Split screen showing the platform with a screen reader active and keyboard focus indicators visible]**

**Narrator:** The BookReview Platform has been designed with accessibility as a priority, following WCAG 2.1 AA standards. Let's explore how to navigate and use all features with screen readers and keyboard controls.

## Screen Reader Compatibility (0:30 - 1:00)

**[Visual: Logos of supported screen readers appear]**

**Narrator:** The BookReview Platform works with all major screen readers, including:
- JAWS
- NVDA
- VoiceOver
- TalkBack
- Narrator

**[Visual: Screenshot of platform with ARIA landmarks highlighted]**

**Narrator:** Our platform uses semantic HTML and ARIA landmarks to ensure screen readers can properly interpret the content and structure of each page.

## Navigation Basics (1:00 - 1:45)

**[Visual: Homepage with keyboard focus indicator moving through elements]**
**[Audio: Screen reader output audible as focus moves]**

**Narrator:** Let's start with basic navigation. When you arrive at the BookReview Platform, you can:

**[Visual: Tab key highlighted as focus moves to skip link]**

**Narrator:** Press Tab to access the "Skip to main content" link, which appears for keyboard and screen reader users. Activating this link bypasses the navigation menu and brings you directly to the main content.

**[Visual: Demonstration of skip link being activated]**

**Narrator:** To navigate through the main sections of any page, use the heading structure. Most screen readers allow you to jump between headings using shortcut keys.

**[Visual: Heading navigation being demonstrated with heading levels shown]**
**[Audio: Screen reader announcing "Heading level 2, Recommended for You"]**

**Narrator:** For NVDA and JAWS users, press H to move to the next heading or 1 through 6 to jump to specific heading levels.

## Main Navigation Menu (1:45 - 2:15)

**[Visual: Focus moves to the main navigation menu]**

**Narrator:** The main navigation menu is implemented as a proper navigation landmark. Screen reader users can jump directly to it using the landmarks navigation feature of their screen reader.

**[Visual: Menu items receiving focus with expanded states clearly visible]**

**Narrator:** Menu items with dropdowns are properly announced as expanded or collapsed. When focused, your screen reader will indicate if a menu has a submenu.

**[Audio: Screen reader announcing "Browse Books, has submenu, collapsed"]**

**Narrator:** Use Enter or Space to expand dropdown menus, then Tab or arrow keys to navigate their contents.

## Book Search and Results (2:15 - 2:45)

**[Visual: Search form with focus on the search input]**

**Narrator:** The search feature is fully accessible. Navigate to it using Tab or your screen reader's form controls navigation.

**[Visual: Search being performed with screen reader feedback]**
**[Audio: Screen reader announcing "Search results, 5 items"]**

**Narrator:** Search results are announced with the total count. Each result is structured as an article with proper headings and descriptions. Use your screen reader's reading commands to explore each result, or Tab through the actionable elements.

**[Visual: Focus moving through search result items]**

**Narrator:** Each book title is a proper link to the book's detail page, and rating information is properly labeled.

## Book Details and Reviews (2:45 - 3:15)

**[Visual: Book detail page with screen reader focus]**

**Narrator:** On book detail pages, content is organized in clearly labeled sections. The rating system is implemented with ARIA to ensure screen readers announce the correct star ratings.

**[Audio: Screen reader announcing "4.5 out of 5 stars rating"]**

**Narrator:** Review forms are fully accessible with properly labeled form controls. Required fields are announced by screen readers, and error messages are linked to their corresponding fields.

**[Visual: Focus moving through a review form with labels clearly visible]**

## Keyboard Shortcuts (3:15 - 3:40)

**[Visual: Table of keyboard shortcuts appears]**

**Narrator:** The BookReview Platform offers several keyboard shortcuts to enhance accessibility:

- Alt+H or Option+H: Return to homepage
- Alt+S or Option+S: Jump to search
- Alt+N or Option+N: Navigate to notifications
- Alt+P or Option+P: Go to your profile
- Alt+R or Option+R: Jump to recommendations
- Esc: Close dialogs or expanded menus

**[Visual: Each shortcut being demonstrated]**

**Narrator:** Access the complete list of keyboard shortcuts by pressing Alt+K or Option+K from any page.

## Conclusion (3:40 - 3:45)

**[Visual: BookReview Platform logo with accessibility icon]**

**Narrator:** We're committed to making the BookReview Platform accessible to everyone. If you encounter any accessibility issues or have suggestions for improvement, please contact our support team through the Accessibility Feedback form in the Help Center.

**[Visual: Contact information and accessibility statement link]**

**Narrator:** Thanks for watching. Happy reading!

**[END OF VIDEO]**
